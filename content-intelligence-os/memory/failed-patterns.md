# Failed Patterns — Empire Laws

Patterns to avoid: confirmed by 2+ of our own videos, plus single-occurrence "candidate failures" clearly marked provisional. Maintained by the Learning Brain. When a failed pattern is confirmed AND brand-damaging, the cohort review proposes graduating it to `brands/empire-laws/forbidden-patterns.md` (a hard ban).

## Why This File Gets Equal Rigor

Negative knowledge saves production slots. "X doesn't work for us" is worth 20–60 hours every time it prevents a doomed production. Failures are documented with the same evidence discipline as wins (learning rule: negative knowledge is knowledge).

## Entry Format

```
### F-[number]: [pattern, stated specifically enough to be recognized in a future idea]
- Status: CANDIDATE (1 occurrence, provisional) / CONFIRMED (2+)
- Occurrences: [videos, dates, metric evidence]
- Failure mode: [packaging (CTR) / content (retention) / brand (wrong audience)]
- Suspected cause: [named variable + confidence]
- Escalation: [none / proposed for forbidden-patterns.md on YYYY-MM-DD]
```
