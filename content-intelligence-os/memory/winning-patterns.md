# Winning Patterns — Empire Laws

Patterns with **2+ confirmations from our own videos** that future videos should deliberately repeat. Maintained by the Learning Brain per `brain/learning-rules.md`: two confirmations promote; 20 videos without reconfirmation demotes back to candidate.

## Lifecycle

```
observation (1 video) → CANDIDATE → 2nd confirmation → CONFIRMED → 20 videos unconfirmed → demoted
```

External patterns (from competitor analysis or platform research) enter as candidates only — never as confirmed — until our own data confirms them (learning rule: no outsourced conviction).

## Entry Format

```
### W-[number]: [pattern, stated as a repeatable instruction]
- Status: CANDIDATE / CONFIRMED | First seen: [video, date] | Confirmations: [videos]
- Last confirmed: YYYY-MM-DD
- Evidence: [the metric deltas that support it]
- How to apply: [which agent/stage uses this, concretely]
- Boundary: [where the pattern does NOT apply, if known]
```
